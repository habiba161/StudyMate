# StudyMate Frontend

Frontend implementation for StudyMate using HTML, CSS, JavaScript, and Node.js (Express).

## Pages included
- Landing page
- Sign up
- Login
- Dashboard
- Upload Notes
- Generate Quiz
- AI Explanation
- Progress Tracker
- Profile

## Run locally
```bash
npm install
npm start
```

Then open:
```bash
http://localhost:3000
```

## Notes
This version is focused on the frontend UI to match the wireframes. The buttons and forms are ready to be connected to backend APIs later.
